# My Engineering Projects

A home for my engineering projects and coding learning. The goal is to keep everything I build in one place so I can see my progress over time.

## Structure

Each project lives in its own self-contained folder, and each project has its own branch. `main` only holds this README and the shared repo files; switch to a project's branch to see its folder.

```
main                  # this README and .gitignore only
├── c-cpp-learning    # branch: adds the c-cpp-learning/ folder
└── beginner-projects # branch: adds the beginner-projects/ folder
```

## Conventions

- One branch per project, with one self-contained folder per branch.
- Keep code small, runnable and commented where the idea isn't obvious.
- Add new projects to the table above, with their branch.
