# Beginner Projects

Five small hardware projects, built in order on an Arduino or STM32 board:

1. LED and button
2. Temperature and humidity logger with Python plots
3. IMU tilt sensor with a complementary filter
4. DC motor speed control with PID and an encoder
5. KiCad breakout board for an STM32

Each project folder holds a README, `src/` (my code), `docs/` (photos, GIFs, notes) and `data/` (measurements and plots).
